🍵 NAGOMI — le bot du serveur
================================

CE QU'IL Y A DANS LES DOSSIERS
  index.js        → démarre le bot. Tu n'y touches JAMAIS.
  commandes/      → UNE commande = UN fichier qui porte son nom (ex : ban.js = /ban)
      membres/      /aide /ping /avatar /userinfo /serverinfo /rank /top
      moderation/   /ban /unban /kick /mute /unmute /warn /warns /unwarn /clear /lock /unlock /slowmode
      serveur/      /setup /config /embed /dire /emoji /reactionrole /autorole /ticket /palier /xp /bienvenue
  systemes/       → ce qui tourne tout seul (rôles-réactions, rôles automatiques…)
  reglages/       → ce que TU peux changer : couleurs.js, textes.js, structure.js (le plan des salons)
  outils/         → petits morceaux partagés (tu n'as pas à y toucher)
  donnees/        → les sauvegardes du bot (créé tout seul)

POUR AJOUTER UNE COMMANDE PLUS TARD
  Dépose un fichier dans le bon dossier de commandes/. Rien d'autre à modifier.

──────────────────────────────────────────────
MISE EN LIGNE (une seule fois)
──────────────────────────────────────────────
1) Portail développeur Discord (discord.com/developers/applications)
   → "New Application" → nom : Nagomi
   → onglet "Bot" : "Reset Token" puis COPIE le token (garde-le secret !)
   → toujours dans "Bot", descends à "Privileged Gateway Intents" et active :
        ✔ SERVER MEMBERS INTENT
        ✔ MESSAGE CONTENT INTENT   (nouveau : sert aux logs des messages modifiés/supprimés)
   → "Save Changes"

2) Inviter le bot sur ton serveur
   → onglet "OAuth2" → "URL Generator"
   → coche "bot" ET "applications.commands"
   → en dessous, coche "Administrator"
   → copie le lien en bas, ouvre-le, choisis ton serveur Nagomi

3) GitHub : crée un NOUVEAU dépôt (ex : nagomi-bot) et glisse-y TOUT le contenu
   de ce dossier (index.js, package.json, commandes, systemes, reglages, outils…).
   Ne glisse PAS le dossier node_modules.

4) Railway : "New Project" → "Deploy from GitHub repo" → choisis nagomi-bot
   → onglet "Variables" → ajoute :
        DISCORD_TOKEN  =  (le token copié à l'étape 1)
        GUILD_ID       =  (l'ID de ton serveur : clic droit sur le serveur → Copier l'identifiant)
   → onglet "Settings" → "Volumes" → ajoute un volume monté sur  /app/data
     (sinon les avertissements et réglages sont perdus à chaque redémarrage)

5) Dans les logs Railway tu dois voir :
        🍵 Nagomi est prête : 47 commandes …

──────────────────────────────────────────────
PREMIER PARAMÉTRAGE DU SERVEUR
──────────────────────────────────────────────
1. Dans Discord : Paramètres du serveur → Rôles → glisse le rôle "Nagomi" (le bot) tout en HAUT.
2. Tape /setup → bouton "Créer la structure" : rôles + catégories + salons + permissions.
3. Tape /config pour vérifier le salon des logs, le rôle Équipe, le rôle Membre.
4. Écris le règlement : /embed (un formulaire s'ouvre : titre, texte, couleur, image).
5. Donne le rôle ✦ Membre : poste un message dans le règlement, puis
   /reactionrole action:ajouter message:(lien du message) emoji:🌸 role:✦ Membre
6. Tes émojis : /emoji nom:thé image:(fichier)   ou colle un émoji d'un autre serveur.

──────────────────────────────────────────────
SI ÇA NE MARCHE PAS
──────────────────────────────────────────────
• "Missing Permissions" → le rôle du bot n'est pas assez haut (voir étape 1).
• Les commandes n'apparaissent pas → vérifie GUILD_ID et le lien d'invitation (applications.commands).
• Le bot ne démarre pas → regarde les logs Railway et envoie-moi la ligne d'erreur.

──────────────────────────────────────────────
TICKETS
──────────────────────────────────────────────
1. /setup crée la catégorie "🎫 ・ Les tickets" et le salon "🎟️・tickets" (sinon : /config → Catégorie des tickets).
2. Dans le salon des tickets, tape /ticket action:panneau → le message avec le menu apparaît.
3. Un membre choisit une raison → un salon privé s'ouvre pour lui + l'équipe.
4. Fermer = bouton 🔒 (ou /ticket action:fermer) → la conversation est envoyée dans les logs.
   /ticket action:ajouter membre:@x  ou  action:retirer  pour gérer qui voit le ticket.
Les raisons du menu se changent dans reglages/tickets.js.

──────────────────────────────────────────────
NIVEAUX ET RÔLES DE PALIERS
──────────────────────────────────────────────
Chaque message rapporte 15 à 25 XP (1 fois par minute maximum par personne).
1. Associer un rôle à un niveau (tes rôles existants) :
     /palier action:ajouter niveau:5 role:@MonRôle
   Répète pour chaque palier. /palier action:liste pour tout voir.
2. Un seul rôle à la fois ou on les garde tous ?
     /palier action:mode choix:remplacer     (ou : garder)
3. Salon des annonces de niveau :
     /palier action:annonces salon:#niveaux
4. Donner les rôles à ceux qui ont déjà le niveau : /palier action:appliquer
5. Voir un exemple d'annonce : /palier action:test
Les membres : /rank (leur niveau) et /top (classement).
Le staff : /xp pour ajouter, retirer, fixer un niveau ou remettre à zéro.
IMPORTANT : le rôle du bot doit être AU-DESSUS des rôles de paliers dans la liste des rôles.

──────────────────────────────────────────────
BIENVENUE ET AU REVOIR
──────────────────────────────────────────────
1. Salons :   /bienvenue action:salon salon:#bienvenue
              /bienvenue action:aurevoir salon:#au-revoir
   (/setup les règle tout seul)
2. GIF :      /bienvenue action:image pour:bienvenue fichier:(ton GIF)
              /bienvenue action:image pour:au revoir fichier:(ton GIF)   ← 8 Mo maximum
3. Voir le résultat (visible que par toi) : /bienvenue action:apercu
4. Les textes se changent dans reglages/messages.js.


🎁 GIVEAWAYS (v1.7)
   /giveaway lot:Sachet surprise duree:3j gagnants:2     → lance un giveaway (dans le salon où tu écris, ou salon:#giveaways)
   Options en plus : conditions:, bonus:True (boosters = 2 chances), role:, niveau:
   /giveaway action:terminer message:<lien>   → tirage tout de suite
   /giveaway action:reroll message:<lien>     → retire un(e) nouveau/nouvelle gagnant(e)
   /giveaway action:annuler message:<lien>    → supprime sans gagnant
   /giveaway action:liste                     → giveaways en cours
   /giveaway action:banniere fichier:(GIF)    → change l'image des prochains giveaways
   (la bannière salon de thé est déjà fournie : images/giveaway.gif)

   Les membres cliquent sur 🌸 Participer ; ils peuvent annuler (avec confirmation).
   La fin est automatique (même après un redémarrage, grâce au volume Railway).

   /blacklist action:ajouter membre:@x duree:7j raison:...   → interdit les giveaways, retrait automatique à la fin
   /blacklist action:role role:@Blacklisté                  → rôle donné pendant la blacklist (facultatif)
   /blacklist action:liste | retirer


🎁 DROPS (v1.8)
   /drop lot:Un sachet surprise [salon:#giveaways]
   → un message avec un bouton « 🌸 Attraper ! » : le/la PREMIER(E) qui clique gagne.
   Le bot annonce la gagnante et l'envoie ouvrir un ticket. Sans clic pendant 24 h, le drop expire.

📋 LOGS (v1.8) — comme Carl-bot
   /logs action:salon salon:#logs                       → salon de tous les logs
   /logs action:salon categorie:messages salon:#autre   → un salon à part pour une catégorie
   /logs action:desactiver categorie:vocal              → couper une catégorie (activer pour la remettre)
   /logs action:voir                                    → état de chaque catégorie
   Catégories : messages (modifiés/supprimés), membres (arrivées, départs, pseudo),
   rôles, salons, vocal, modération (ban, débannissement, sourdine).
   ⚠️ Active « MESSAGE CONTENT INTENT » dans le portail développeur, sinon le texte des messages reste vide.
   Les messages envoyés AVANT le démarrage du bot s'affichent « contenu inconnu » à la suppression (limite de Discord).


🛡️ AUTOMOD + ANTI-RAID (v1.9)  — pas de règle sur les majuscules
   /automod action:voir                                   → l'état de chaque règle
   /automod action:activer regle:liens                    → (liens désactivés par défaut) ; desactiver pour couper
   /automod action:mot texte:motinterdit                  → ajoute un mot interdit (refaire = retirer) puis activer regle:mots
   /automod action:lien texte:tenor.com                   → site autorisé quand la règle « liens » est active
   /automod action:exempter role:@Rôle  (ou salon:#x)    → ignoré par l'automod
   /automod action:regler reglage:spamMessages valeur:8   → changer un nombre
   /automod action:raid                                   → arrêter le mode raid
   Déjà actif par défaut : invitations Discord, mentions en masse (5 max), spam (6 msgs en 5 s).
   Après 3 infractions en 10 min : sourdine de 10 min. L'équipe n'est jamais sanctionnée. Tout est écrit dans les logs.
   Anti-raid : 6 arrivées en 15 s → les nouveaux sont mis en sourdine 10 min + alerte dans les logs.

🎀 INVITATIONS (v1.9)
   Le message de bienvenue indique maintenant « Invité(e) par … · N invitations » (même message, pas de doublon).
   /invites [membre]   → son nombre d'invitations (total, parties, restantes)
   Le bot compte à partir du moment où il est là : les anciennes invitations ne sont pas connues.
   (Permission « Gérer le serveur » nécessaire : déjà incluse avec Administrateur.)

🌸 CARTE DE NIVEAU (v1.9)
   /rank [membre]  → une image rose et crème avec ton avatar, ta barre d'XP, ton rang et une petite tasse de thé.

💾 SAUVEGARDE (v1.9)
   /sauvegarde action:creer       → sauvegarde maintenant (rôles, salons, permissions, rôles des membres, réglages du bot)
   /sauvegarde action:liste       → toutes les sauvegardes (une automatique par jour, les 7 dernières gardées)
   /sauvegarde action:restaurer   → recrée ce qui a été supprimé (ne supprime rien, ne touche pas à l'existant)
   /sauvegarde action:exporter    → t'envoie le fichier : garde-en un de côté !
   Les sauvegardes sont dans le volume Railway (/app/data/sauvegardes).


💌 INVITER UN(E) PROCHE (v1.10)
   /inviter membre:@copine message:Coucou, viens voir mon serveur !
   → elle reçoit un joli message privé Nagomi avec un bouton « Rejoindre Nagomi »
     (lien personnel : 1 seule utilisation, valable 7 jours).
   Tu peux coller son identifiant Discord dans « membre » même si elle n'est pas encore sur le serveur
   (Discord : Paramètres > Avancés > Mode développeur, puis clic droit sur son profil > Copier l'identifiant).
   Garde-fous : 5 invitations par jour et par personne de l'équipe, une seule invitation par personne.
   Si ses messages privés sont fermés, le bot te le dit : envoie-lui alors le lien toi-même.
   Quand elle arrive, le message de bienvenue indique qu'elle a été invitée par toi.


🪪 QUESTIONNAIRE D'ARRIVÉE (v1.12)
   Le membre donne son pseudo MSP et son serveur MSP (FR, UK…), choisit ses rôles (genre, âge, version MSP, couleur, centres d'intérêt)
   ET réagit au règlement (avec l'emoji que tu choisis). Seulement quand les deux sont faits (dans n'importe quel ordre), le bot lui donne
   le rôle ✦ Membre : c'est ce rôle qui ouvre le serveur.
   Le bot NE CRÉE PAS les rôles : il utilise ceux qui existent déjà.

   Mise en place (une seule fois) :
   1. /config → choisis le « Rôle Membre » (celui qui donne accès au serveur).
   2. Sur Discord, rôle @everyone : retire « Voir les salons » partout, SAUF dans le salon du règlement
      (où @everyone peut voir mais pas écrire). Les salons du serveur ne sont visibles que par le rôle Membre.
   3. Mets le rôle du bot AU-DESSUS de tous les rôles du questionnaire (Paramètres > Rôles).
   4. Pour chaque question, indique tes rôles existants :
        /questionnaire roles question:1 role1:@Femme role2:@Homme role3:@Autre
        /questionnaire roles question:2 role1:@+18 role2:@-18
        /questionnaire roles question:3 role1:@MSP1 role2:@MSP2 role3:@MSP City   (plusieurs choix possibles)
        /questionnaire roles question:4 role1:… jusqu'à role12:…                   (les couleurs)
        /questionnaire roles question:5 …                                          (facultatif : acheteuse, vendeuse…)
   5. /questionnaire reglement salon:#règlement message:<identifiant du message> [emoji:🌸] → le bot pose lui-même l'emoji dessous (par défaut 🍵).
      Tu peux mettre n'importe quel emoji, même un emoji personnalisé de ton serveur. Relance la commande pour en changer.
      (identifiant : Discord > Paramètres > Avancés > Mode développeur, puis clic droit sur le message > Copier l'identifiant)
   5b. /questionnaire panneau salon:#règlement → poste le message avec les boutons « Commencer » et « Modifier mon profil ».
   6. /questionnaire etat → vérifie que tout est réglé.

   Règles : un pseudo (sur un même serveur MSP) = un compte Discord (si quelqu'un utilise le pseudo d'un autre, il est refusé et l'équipe est prévenue
   dans le salon de logs). /questionnaire interdire pseudo:xxx bloque un pseudo d'arnaqueur.
   Quelqu'un qui quitte puis revient retrouve ses rôles sans refaire le questionnaire.

   /profil membre:@x (ou pseudo:xxx, serveur:FR si besoin)        → voir le pseudo MSP et les rôles choisis (équipe)
   /profil membre:@x action:changer le pseudo nouveau:xxx
   /profil membre:@x action:réinitialiser   → il/elle refait le questionnaire
   Le membre peut changer ses rôles seul(e) avec « Modifier mon profil » ; le pseudo, seule l'équipe peut le changer.


📣🎂🎮 MESSAGES AUTO, ANNIVERSAIRES, MINI-JEUX (v1.13)
   MESSAGES AUTOMATIQUES (équipe)
   /auto ajouter salon:#ventes message:Attention aux arnaques ! frequence:chaque semaine [titre:…]
   /auto liste · /auto tester numero:1 (envoie tout de suite pour voir le rendu) · /auto retirer numero:1
   Rythmes : toutes les 6 h, 12 h, chaque jour, chaque semaine. Écris \n dans le message pour passer à la ligne.

   ANNIVERSAIRES
   /anniversaire salon salon:#général  (équipe : le salon où le bot souhaite, chaque jour vers 9 h)
   /anniversaire definir jour:14 mois:3 · /anniversaire retirer · /anniversaire prochains
   Seuls le jour et le mois sont gardés (pas d'année ni d'âge : plus respectueux pour les -18).

   MINI-JEUX
   /pendu       → un mot du monde MSP ; tout le monde tape une lettre (ou le mot entier) dans le salon.
   /quiz lancer → (équipe) une question, le plus rapide à cliquer la bonne réponse gagne. 30 secondes.
   /quiz ajouter question:… bonne:… fausse1:… [fausse2, fausse3] → ajoute TES questions. /quiz liste · /quiz retirer
   (3 questions d'exemple sont déjà là : vérifie-les et ajoute les tiennes !)

   ACTUALITÉS MSP (Instagram) : pas possible proprement (Instagram interdit les robots). Alternative : poste les news
   toi-même avec /embed ou /dire, ou programme un rappel avec /auto.


🧵 LOGS EN FILS PRIVÉS (v1.14)
   /logs action:fils salon:#logs-staff
   → Nagomi crée un fil PRIVÉ par catégorie dans ce salon (réservé à l'équipe) :
     💬 messages · 👤 membres · 🎀 rôles · 📁 salons · 🔊 vocal · 🔨 modération · 🎫 tickets (avec les transcriptions) · 🤖 bot
   Le bot rouvre un fil archivé, ou le recrée s'il a été supprimé.
   Permissions à donner au bot dans ce salon : Voir le salon, Créer des fils privés, Envoyer des messages dans les fils, Gérer les fils.
   Pour que l'équipe voie les fils privés, le bot donne « Gérer les fils » au rôle Équipe sur ce salon (si /config est réglé).
   /logs action:sans-fils → retour aux salons habituels. /logs action:voir → l'état.


🎙️🔢 VOCAUX TEMPORAIRES ET COMPTEUR DE MEMBRES (v1.15)
   SALONS VOCAUX TEMPORAIRES
   1. Crée un salon vocal « ➕ Créer mon salon » (dans la catégorie voulue).
   2. /vocal activer salon:#➕-créer-mon-salon [nom:🍵・{pseudo}]
   → Quand quelqu'un y entre, Nagomi crée un salon vocal à son nom, l'y déplace, et lui donne le droit de le gérer
     (renommer, limiter le nombre de places…). Le salon disparaît quand tout le monde est parti.
   /vocal etat · /vocal desactiver
   Permissions du bot : Gérer les salons + Déplacer des membres.

   COMPTEUR DE MEMBRES
   /compteur ajouter salon:#vocal [modele:🌸・Membres : {n}]
   → le nom du salon affiche le nombre de membres, mis à jour toutes les 10 minutes (limite de Discord).
   Le salon est fermé à la connexion. /compteur retirer salon:#vocal


📊 STATISTIQUES : /stat (v1.16)
   /stat [membre:@x] → une seule carte avec :
     💬 messages envoyés (aujourd'hui · 7 jours · 30 jours)
     🎙️ temps passé en vocal (aujourd'hui · 7 jours · 30 jours)
     🎀 invitations (actuelles, total, parties)
     🌸 niveau et rang
   Le comptage commence le jour de l'installation (rien avant). Le salon vocal AFK n'est pas compté.
   Les données sont gardées 40 jours (volume Railway).
